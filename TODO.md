## Важно — неполная реализация существующих фич

### 6. Короткое замыкание AND / OR
`&` и `OR` реализованы побитовыми `and`/`or`. По спецификации Oberon-7 это операторы с коротким замыканием: если левый операнд определяет результат, правый не вычисляется. Нужны условные переходы (`beqz`/`bnez`) с пропуском правого операнда.

**Файлы:** `RiscVCodeGen.cpp` (visit(BinaryExpr&), cases And/Or).

### 7. ARRAY — полноценная поддержка
- Индексация работает только для word-sized (4 байта) элементов (`slli a0, a0, 2`)
- Нет проверки границ (опционально)
- Нет поддержки не-word элементов (CHAR = 1 байт, BOOLEAN = 1 байт)
- Нет многомерных массивов (`ARRAY N, M OF ...`)
- Нет открытых массивов (`ARRAY OF`) в параметрах

**Файлы:** `RiscVCodeGen.cpp` (emitAddress — IndexSelector, resolveType — ArrayType).

### 8. CHAR — байтовый доступ
Все типы грузятся через `lw`/`sw` (4 байта). CHAR должен использовать `lb`/`sb` (1 байт). Глобальные CHAR — `.byte` вместо `.word`.

**Файлы:** `RiscVCodeGen.cpp` (visit(VarDecl&), emitLoad, emitAddress, visit(AssignStmt&)).

### 9. REAL арифметика
Литерал сохраняется как битовый паттерн в целом регистре. Нет FPU-инструкций:
- `fadd.s`, `fsub.s`, `fmul.s`, `fdiv.s` для арифметики
- `flw`, `fsw` для загрузки/сохранения
- `fcvt.w.s`, `fcvt.s.w` для конвертации
- `feq.s`, `flt.s`, `fle.s` для сравнений
- Использование регистров `f0`–`f31` / `fa0`–`fa7`

**Файлы:** `RiscVCodeGen.cpp` (visit(LiteralExpr&), visit(BinaryExpr&), emitLoad, visit(VarDecl&)).

### 10. VAR-параметры — тестирование
Флаг `isVarParam` в `SymbolTable` есть, обработка в `emitAddress` есть (загрузка адреса вместо значения), но отсутствует e2e-тест. Нужен тест с `PROCEDURE Swap(VAR a, b: INTEGER)`.

**Файлы:** `tests/e2e/programs/` — новый тест.

### 11. FOR с отрицательным BY
Сейчас всегда используется `bgt` (i > to → end). Для `BY < 0` нужен `blt` (i < to → end). Необходимо определять знак шага на этапе компиляции или генерировать проверку обоих направлений.

**Файлы:** `RiscVCodeGen.cpp` (visit(ForStmt&)).

### 12. WHILE ELSIF DO
Oberon-07 допускает `WHILE c1 DO s1 ELSIF c2 DO s2 END`. Нужно проверить, что AST корректно хранит множественные ветки, и генерировать код для каждой.

**Файлы:** `RiscVCodeGen.cpp` (visit(WhileStmt&)).

## Продвинутые фичи

### 13. IS (type test) и type guard v(T)
Динамическая проверка типа для расширенных RECORD. Требует:
- Type tag (скрытое поле) в каждом RECORD
- Генерация таблицы type descriptors
- Код для `IS`: сравнение tag с ожидаемым
- `TypeGuardSelector`: проверка + приведение типа

**Файлы:** `RiscVCodeGen.cpp` (visit(BinaryExpr&) — default/IS, visit(TypeGuardSelector&)), `TypeInfo.h`.

### 14. IMPORT — модульная система
`visit(Import&)` пуст. Модули `Out`, `In`, `Math` зашиты как builtins. Нужно:
- Реестр встроенных модулей с их символами
- Разрешение квалифицированных имён (`Out.Int`, `Math.Sin`)
- В перспективе — загрузка пользовательских модулей

**Файлы:** `RiscVCodeGen.cpp` (visit(Import&), tryEmitBuiltinCall).

### 15. Экспортные метки (*)
Идентификаторы с `*` (например `PROCEDURE Foo*`) должны быть видны из других модулей. Сейчас экспортные метки игнорируются.

**Файлы:** `RiscVCodeGen.cpp`, `SymbolTable.h` (добавить `isExported` в `Symbol`).

### 16. Вложенные процедуры — static link
Вложенные `PROCEDURE` не видят локальные переменные родительской процедуры. Нужен static link (указатель на frame родителя) или display.

**Файлы:** `RiscVCodeGen.cpp` (visit(ProcDecl&), emitAddress), `SymbolTable.h`.

### 17. Процедурные переменные (PROCEDURE TYPE)
Хранение адреса процедуры в переменной, вызов через `jalr` по указателю.

**Файлы:** `RiscVCodeGen.cpp` (visit(DesignatorExpr&)), `TypeInfo.h`.

### 18. Передача >8 параметров через стек
Сейчас используются только регистры `a0`–`a7`. При >8 параметрах нужна передача через стек по ABI.

**Файлы:** `RiscVCodeGen.cpp` (visit(ProcDecl&), visit(DesignatorExpr&) — вызов функций).

### 19. STRING операции
Сейчас строковые литералы только помещаются в `.data`. Нужно:
- Сравнение строк (побайтовый цикл)
- Присваивание строк (`COPY`)
- Доступ по индексу как `ARRAY OF CHAR`

**Файлы:** `RiscVCodeGen.cpp`.

### 20. Раздельная компиляция модулей
- Генерация `.globl` для экспортированных символов
- Линковка нескольких `.asm` файлов
- Формат символьного файла (`.smb`) для типов и сигнатур

**Файлы:** `src/main.cpp`, `RiscVCodeGen.cpp`.
